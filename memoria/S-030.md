# S-030 · Historial privado de Maximus, separado de /admin

Ricardo preguntó cómo revisar sus conversaciones con Maximus sin
exponerlas a quien tiene la clave compartida de `/admin` (Caja). Al
revisar el código para responder eso, se encontró un hueco real, no
solo la pregunta original.

## El hueco encontrado — Telegram no estaba filtrado

`es_privada()` en `agent/memory.py` reconocía el WhatsApp de Ricardo y el
cerebro web (`web:`), pero **no su Telegram** (`tg:{chat_id}`) — el canal
principal desde `D-010`, justamente porque WhatsApp tiene la limitación
de ventana de 24h. Cualquiera con la clave de `/admin` podía leer esas
conversaciones. Causa: `es_maximus()` compara contra el número de
WhatsApp (`MAXIMUS_OWNER_PHONES`), y el chat_id de Telegram normalizado a
dígitos nunca calza con ese número — nadie lo notó porque las pruebas de
`P-011`/`H-019` se hicieron mirando el WhatsApp, no el Telegram.

**Corregido:** `es_privada()` ahora reconoce el prefijo `tg:` y valida
contra `TELEGRAM_OWNER_CHAT_IDS` (`agent.telegram_maximus.es_owner()`).
Ante cualquier error, una clave `tg:` se trata como privada por defecto
(fail closed) — al revés que el resto de la función, porque una clave con
ese prefijo nunca puede ser un cliente real.

## El visor nuevo — `/maximus/historial`

Página HTML simple, protegida con `MAXIMUS_CHAT_TOKEN` (mismo token que
`/maximus/display`, acepta `?token=` en la URL para abrir directo del
navegador) — no la clave compartida de `/admin`. Lista las tres
conversaciones privadas de Ricardo (WhatsApp, Telegram, cerebro web) y
el detalle de cada una. El endpoint de detalle vuelve a chequear
`es_privada()` del lado del servidor — nunca sirve una conversación de
cliente aunque alguien adivine la clave.

**No resuelve `P-011` completo** (separación física de la base de datos)
— sigue siendo la misma tabla, solo con dos puertas de acceso distintas.
Suficiente para el riesgo real de hoy (alguien con la clave de Caja
leyendo los chats de Ricardo); la separación física sigue pendiente,
prioridad baja, para cuando se pueda probar con calma.

**Verificado en producción, 31-ago-2026** (con una demora por confusión
de token — Ricardo probó primero un placeholder literal y después un
token con un punto pegado al final por error de copiado; se resolvió
verificando el valor exacto en el `.env` del servidor).

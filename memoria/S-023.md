# S-023 · Vigilante de maximus-agent — 26-ago-2026

Primer paso concreto de `D-012` (estabilidad antes que funciones nuevas).
`scripts/monitor-maximus.ps1`, registrado como Tarea Programada
`Maximus-Vigilante`, corre cada 5 minutos:

1. Revisa la salud de `maximus-agent` (`http://localhost:8000/`).
2. Si falla, mira quién tiene el puerto 8000. Si es un proceso que PM2 no
   reconoce como el suyo — el patrón exacto de los tres zombis de H-021 —
   lo mata antes de reintentar.
3. Reinicia con `pm2 restart maximus-agent`.
4. Si sigue caído, avisa por Telegram **directo por la API del bot**, no a
   través del agente — funciona aunque `maximus-agent` esté completamente
   abajo. Mismo bot y chat_id que ya usa Maximus para hablarle a Ricardo.

Si todo está sano, el script no hace nada y no escribe nada en el log — un
log vacío es la señal correcta, no un fallo.

## Dos bugs reales en el despliegue, los dos de PowerShell/Windows

1. **Un bloque de comentario con comillas anidadas y `` ` `` de
   continuación de línea rompió el parser entero** — cascada de errores
   "falta llave de cierre" en líneas que nada tenían que ver con el
   problema real. Se sacó ese bloque del archivo (las instrucciones de
   registro quedaron solo en esta nota).
2. **El verdadero problema era de codificación:** el archivo tenía tildes
   y guión largo (á, é, —) en UTF-8 sin BOM. PowerShell 5.1 en Windows a
   veces lee mal ese UTF-8 al bajarlo por git, y las tildes se convierten
   en bytes que el parser interpreta como comillas sueltas — mismo
   síntoma que el bug 1, causa distinta y más profunda. Se reescribió el
   script completo en ASCII puro (sin tildes, sin ñ, sin guión largo) para
   sacarse el problema de encima de raíz, no parchar caso por caso.
3. **`[TimeSpan]::MaxValue` no es una duración válida para
   `Register-ScheduledTask`** — genera un XML con `Duration:
   P99999999DT23H59M59S`, fuera de rango. Se cambió a `(New-TimeSpan -Days
   3650)` — diez años, tan "para siempre" como hace falta, pero un valor
   que el esquema de tareas programadas sí acepta.

**Regla derivada, para cualquier script de PowerShell que se escriba
desde acá en adelante:** ASCII puro, sin tildes ni guión largo. No vale la
pena pelear con la detección de codificación de Windows por una comilla
elegante.

**Verificado:** disparado a mano con `Start-ScheduledTask`, log vacío
(correcto, Maximus estaba sano), y confirmado desde afuera con un `curl`
directo a `https://maximus.ngrok.app/` — 200 OK.

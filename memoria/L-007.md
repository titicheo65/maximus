# L-007 · En Base44, editar el archivo de una función no la despliega

Al agregar búsqueda por nombre a `maximusBodega` (DimangoWorking), la edición
se guardó bien en el editor —se veía el código nuevo, `read_file` lo
confirmaba— pero la URL pública siguió sirviendo la versión vieja durante
varios minutos. Ni reescribir el archivo ni borrarlo y recrearlo lo
solucionó.

**Lo que sí funcionó:** Ricardo entró al editor de Base44, abrió la
función y la **publicó explícitamente** (botón "Publish"/"Deploy", fuera
del panel de "Test Function" — el test corre contra el código en
edición, no contra la URL pública). Ahí sí, el endpoint respondió con el
código nuevo al instante.

**Regla derivada:** crear una función Base44 nueva se refleja sola en la
URL pública. **Editar una que ya existe, no** — hace falta un paso de
publicación aparte. Si un endpoint que antes funcionaba deja de reflejar
un cambio después de editarlo, antes de sospechar del código, revisar si
falta publicar.

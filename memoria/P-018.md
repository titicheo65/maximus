Al preparar la rotación se descubrió que **la misma llave la usan los servidores
de impresión de los locales**, no solo la app. Rotarla sin tocarlos habría dejado
a los dos locales **sin imprimir boletas ni comandas** al día siguiente.

Es el mismo error que casi se comete con el Club: cambiar algo verificando solo
el lugar donde uno estaba mirando. **Regla: antes de rotar una credencial hay que
inventariar TODOS sus consumidores, incluidos los que corren fuera del
repositorio.**

3. **Playa** (PowerShell, un bloque por vez):
   ```powershell
   $N = "PEGAR_LLAVE_NUEVA"
   ```
   ```powershell
   foreach ($f in "C:\dimango\print-server\servidor-impresion-playa-v6.js","C:\dimango-wallet\server6.js") { Copy-Item $f "$f.bak-rotacion"; $enc=[Text.Encoding]::GetEncoding(28591); $t=[IO.File]::ReadAllText($f,$enc); [IO.File]::WriteAllText($f,$t.Replace("cf05dc9ec6d149c58382b3c341a6d0bc",$N),$enc) }
   ```
   ```powershell
   pm2 restart impresion-playa server6
   ```
   **Corregido el 10-sep antes de ejecutar:** leer como UTF-8 también es un riesgo,
   porque un `.js` editado con el Bloc de notas de Windows puede estar en ANSI, y
   leerlo como UTF-8 destruye las tildes de lo que se imprime en la boleta. Se
   usa **ISO-8859-1 (página 28591)**, que traduce cada byte 1 a 1: el archivo
   queda idéntico salvo la llave, sea cual sea su codificación original.
4. **Mall**: mismo reemplazo sobre `C:\dimango\print-server\servidor-impresion-mall-v6.js`.
   El `.bat` es `cd /d C:\dimango\print-server` → `node servidor-impresion-mall-v6.js`
   → `pause`, así que el servidor vive en **una ventana de consola abierta**:
   cerrar esa ventana (mata el Node) y volver a hacer doble clic en
   `dimango-print-mall.bat`. Confirmar que la ventana nueva queda abierta y sin error.
5. **Verificar**: impresión de prueba en cada local, búsqueda de socio desde el

**El `.bak` sirve si el reemplazo corrompe el archivo, NO para deshacer la
rotación**: una vez regenerada, la llave vieja ya no funciona. Si algo falla,
